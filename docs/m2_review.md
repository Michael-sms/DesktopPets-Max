# M2 单角色闭环审阅指引

## 本轮完成范围

- 支持 JPG、PNG、WebP 照片导入和本地质量检查。
- 必须确认照片及主体形象授权后才能建立项目。
- 检查分辨率、比例、亮度和细节，并提取三色参考色板。
- 建立可编辑的角色规格草稿和生成简报。
- 图像生成通过 Provider 接口隔离：内置样例用于离线审阅，可选 OpenAI Provider 用于真实图片编辑。
- 提供三个候选方案和显式选择。
- 提供三项人工审阅关卡：身份特征、形象喜好、允许继续制作动作。
- 选择通过后生成关键姿势表、12 帧无漂移 Idle 呼吸循环、资源清单和审批记录。
- 已确认角色可以从制作界面直接启动为桌宠。

## 推荐审阅流程

运行：

```powershell
.venv\Scripts\python.exe main.py --create-demo
```

然后按顺序执行：

1. 检查内置样例的分辨率、亮度、细节分数和提取色板。
2. 修改角色名称、发型、眼睛、服装或补充说明。
3. 点击“生成 3 个候选方案”，比较三个饱和度轻微不同的离线候选。
4. 选择一个方案，勾选三项审阅条件。
5. 点击“确认并生成 Idle 动画”，检查右侧关键姿势表和 Idle 预览。
6. 点击“启动已确认桌宠”，确认 12 帧 Idle 循环可以被 M1 播放器读取。

## 真实照片模式

运行 `main.py --create` 后可导入自己的照片。照片只在本地复制到 `workspace/creation_projects/`，并生成：

- `project.json`
- `character_spec.json`
- `generation_brief.md`
- `source/source.<ext>`

未配置 AI Provider 时，流程会停在“候选生成”之前并明确提示，不会用样例角色冒充照片生成结果。配置 Provider 后才会调用图片编辑服务生成三个候选和关键姿势表。

本项目的可选实现依据官方 OpenAI 图片生成文档：Image API 适合单次生成/编辑，`gpt-image-2` 支持图片编辑和高保真图片输入；由于该模型当前不支持透明背景，候选图使用纯色边界并在本地清除背景。[官方图片生成指南](https://developers.openai.com/api/docs/guides/image-generation)

## M2 范围说明

- 本阶段只将 Idle 做成正式的 12 帧资源。
- Hover、Loading、Working 在 M2 角色包中使用已确认锚点图作为静态回退，避免提前进入 M3 动作制作。
- 内置候选的三种变化用于验证选择和审批流程，不代表实际生成服务的候选丰富度。
- M3 应继续制作 Hover、Loading、Working 及状态过渡动画。

## 建议重点反馈

- 照片质量提示是否容易理解。
- 角色规格字段是否足以锁定身份特征。
- 三项确认是否过多或过少。
- 关键姿势表是否适合作为后续动作的统一依据。
- Idle 呼吸幅度和 2.4 秒循环是否自然。
- 生成资源落到 `workspace/` 是否符合隐私预期。
