# M1 规范与原型审阅指引

## 本轮完成范围

- 定义四状态及优先级：`Working > Loading > Hover > Idle`。
- 实现与 GUI 解耦的状态机，忙碌状态不会被 Hover 打断。
- 定义并校验桌宠资源清单 v1。
- 实现透明、无边框、置顶、可拖动的 PySide6 桌面窗口。
- 提供右键调试菜单、数字键切换和自动轮播模式。
- 提供四张占位状态图；Working 使用悬浮终端。
- 提供 manifest 校验、状态机单元测试和离屏启动检查。

## 建议审阅方式

1. 运行 `uv run python main.py --demo`，观察四状态是否容易区分。
2. 正常运行 `uv run python main.py`，检查悬停响应和离开恢复。
3. 用数字键 `1`～`4` 或右键菜单切换状态。
4. 左键拖动桌宠，确认窗口移动符合预期。

占位角色仅用于验证状态语义、尺寸和交互，不代表下一阶段的最终二次元美术质量。

## 建议重点反馈

- 280 × 280 的默认尺寸是否合适。
- 状态标签是否保留到后续开发，或只用于调试模式。
- Loading 的等待感与 Working 的主动操作感是否足够明确。
- Hover 触发延迟 120 ms、离开延迟 200 ms 是否自然。
- 是否接受右键菜单作为首版调试和退出入口。
